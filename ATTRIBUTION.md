# Attribution and media

The application code, teaching prose, deterministic fictional datasets and programmatically rendered data graphics were produced for Evidence Desk with AI assistance. They are supplied under the included MIT licence. No human-testing or independently measured educational efficacy claim is made.

The educator guide identifies three educational references with titles, URLs and the concepts they support. No source diagrams, exercise text, screenshots, photographs or datasets were copied into the learner interface.

System font names are CSS preferences. No font files are embedded or redistributed. No third-party library, external asset, paid endpoint or tracking code ships in `dist/`.

Generated UI reference images were used during design only. They are not runtime assets or scientific evidence and are excluded from the source submission package. The website's actual charts are computed from the bundled synthetic data.

Node.js and browser/automation software are development tools, not redistributed application dependencies. Optional WebMCP integration is feature-detected and uses the browser's API when available; it neither transmits learner answers nor supplies runtime generative-AI functionality.
